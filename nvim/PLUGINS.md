# Nvim Plugins

## Active Plugins

### Core
- **blink.cmp**: スーパー-fast な完結型インテリセンス補完プラグイン
- **nvim-treesitter**: 階層的構文解析による正確な構文ハイライト・インデント
- **nvim-treesitter-context**: カーソル周辺のコドブロックコンテキストを画面上部に固定表示
- **vim-denops / vim-skk / skkeleton**: denops 対応の SKK 日本語入力プラグイン

### UI & Display
- **dashboard-nvim**: 起動時に表示されるカスタマイズ可能なダッシュボード
- **neo-tree.nvim**: 軽量なファイルツリーブラウザー
- **nvim-web-devicons**: ファイルタイプに応じたアイコン表示
- **github-nvim-theme**: GitHub Dark テーマのカラーリング
- **nvim-colorizer.lua**: CSS/HTML などのカラー値を視覚的に確認
- **hlchunk.nvim**: 現在のコードチャンク・インデントを記号で表示
- **dropbar.nvim**: 現在カーソルがあるシンボルを表示するドロップダウンバー
- **nvim-notify**: スムーズな通知表示（vim.notify 互換）

### Navigation & Search
- **fzf-lua**: fzf ベースの高速検索・コマンド実行ツール
- **zoxide.vim**: 頻繁に行くディレクトリに素早く移動
- **vim-tmux-navigator**: tmux ペイン間のキーボード移動
- **neoscroll.nvim**: 自然なスクロールアニメーション
- **smart-splits.nvim**: ウィンドウ境界線を矢印キーでリサイズ
- **flash.nvim**: 素早いジャンプのためのワンタイムラベル付け

### Editing
- **nvim-surround**: 囲む・削除・変更の操作を簡単化
- **neotab.nvim**: 括弧ペアの間に素早く移動・入力
- **marks.nvim**: マーク・ブックマーク管理の改善

### Development
- **nvim-lspconfig / mason-lspconfig**: LSP クライアントの自動セットアップ
- **gitsigns.nvim**: Git 差分のシンマーク表示・ナビゲーション
- **git-worktree.nvim**: Git worktree 管理（記載なし）

### Utilities
- **auto-session**: プロジェクトごとのセッション保存・復元

### Git & Diff
- **codediff.nvim**: コード差分表示
- **linediff.vim**: 行単位の差分表示
- **gitsigns.nvim**: Git 差分のシンボル表示・ナビゲーション

### File & Buffer
- **bufferline.nvim**: 効率的なバッカー管理
- **bigfile.nvim**: 大きなファイルの表示最適化
- **indent-blankline.nvim**: インデントレベルの表示

### Status Line & Navigation
- **lualine.nvim**: カスタマイズ可能なステータスライン
- **trouble.nvim**: ダイアログ・エラー・定義リスト表示
- **zen-mode.nvim**: 没頭モード

## Archived
- **nvim-tree**: File tree plugin (replaced by neo-tree)
